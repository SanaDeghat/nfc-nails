# NFC Nails

NFC nails will be a set of press on nails that utelize nfc technology to act as a buisness card
This is my first use of an nfc chip. It would be inreesting to explore fufutre versions of this design with a mini pcb/ circuit on the nail itself tho that would need a lot of persicion and very small pieces so i think it is better for a future, more expirienced and more locked in me. The porpuse of making this is for the silly's the idea of yappinmg my nails to open my socials is very funny and silly to me (and imma put it on the middle finger) 



The art will be done by hand (by me)! the nfc chip will be connected to my hand by use of glossy top coat and integrated into the art to not look out of place.
Green nail polish will be used as gthebase then the Nfc chip will go on thne the patterns will be drawn with a pencil to then be painted on with a metalic paint using liner brush fo the lines and a dotting tool for the dots.

# PCB

This project does not need a pcb since an NFC chip does not need power to function

# Simple Build Guide :3
1. order the necery pieces (look below :D)
2. Color all nails with a base color
3. put on the NFC sticker on desired nail(s)
4. program the stickers to function as desired
5. draw art around it & on other nails
6. put on a layer of top coat to stick everything and solidify it with UV light
